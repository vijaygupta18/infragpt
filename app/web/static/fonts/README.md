# Fonts

Geist and Geist Mono, by Vercel. Licensed under the SIL Open Font License 1.1,
which permits use in commercial products without royalty or attribution.

Self-hosted deliberately: these are served same-origin by this application, not
pulled from a CDN, so they work under a strict CSP and add no third-party
dependency to a tool used during incidents.

Source: https://github.com/vercel/geist-font
